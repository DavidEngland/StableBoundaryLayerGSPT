WSINDy completes the GSPT-SBL identification pipeline by converting a noise-sensitive, non-smooth differential parameter recovery problem into a well-conditioned linear system $\mathbf{G} \boldsymbol{\Xi} = \mathbf{b}$ via test-function integration.

By applying the desingularized transformation ($\tilde{e} = \sqrt{e + \delta}$) and dynamic time rescaling ($d\tau = \tilde{e} \, dt$), the feature library becomes strictly linear in the unknown physical closure constants ($c_m, c_w, c_\theta, C_\theta$).

---

## 1. Linear-in-Parameters Matrix Formulation

In fast time $\tau$, the fast vector field can be factored into a linear combination of known geometric features and unknown scalar coefficients $\boldsymbol{\Xi} = [c_m, c_w, c_\theta, C_\theta]^T$:

$$\begin{bmatrix} \dot{\tilde{e}} + \frac{g}{2\theta_0} q_\theta + \frac{\tilde{e}^3}{2\ell} \\ \dot{q}_\theta \end{bmatrix} = \begin{bmatrix} \frac{1}{2} \ell z_{\text{eff}} S^2 \tilde{e} & 0 & 0 & 0 \\ 0 & -\theta_z(T_s, \tilde{e}) \tilde{e}^3 & -\frac{g}{\theta_0} \ell q_\theta^2 & -\frac{1}{\ell} \tilde{e}^2 q_\theta \end{bmatrix} \begin{bmatrix} c_m \\ c_w \\ c_\theta \\ C_\theta \end{bmatrix}$$

Because the parameters enter linearly, WSINDy does not require non-convex optimization.

---

## 2. Weak-Form Convolution Operator

Given noisy discrete field observations $\mathbf{x}(t_k)$ over a domain $[0, T]$, WSINDy selects a family of smooth, compactly supported test functions $\phi_j(\tau)$ (e.g., localized polynomials or Gaussians) satisfying $\phi_j(0) = \phi_j(T) = 0$.

Integrating the system against $\phi_j(\tau)$ and applying integration by parts shifts time derivatives away from noisy field data onto the test functions:

$$\int_0^T \frac{d\tilde{e}}{d\tau} \phi_j(\tau) \, d\tau = -\int_0^T \tilde{e}(\tau) \frac{d\phi_j}{d\tau} \, d\tau$$

### Discrete Linear System ($\mathbf{G} \boldsymbol{\Xi} = \mathbf{b}$)

For $M$ test functions $\{\phi_j\}_{j=1}^M$, the integration generates the Gram matrix $\mathbf{G} \in \mathbb{R}^{2M \times 4}$ and target vector $\mathbf{b} \in \mathbb{R}^{2M}$:

$$\mathbf{b} = \begin{bmatrix} -\left\langle \tilde{e}, \phi_j' \right\rangle + \left\langle \frac{g}{2\theta_0} q_\theta + \frac{\tilde{e}^3}{2\ell}, \phi_j \right\rangle \\ -\left\langle q_\theta, \phi_j' \right\rangle \end{bmatrix}, \quad \mathbf{G} = \begin{bmatrix} \left\langle \frac{1}{2}\ell S^2 \tilde{e}, \phi_j \right\rangle & 0 & 0 & 0 \\ 0 & -\left\langle \theta_z \tilde{e}^3, \phi_j \right\rangle & -\left\langle \frac{g}{\theta_0} \ell q_\theta^2, \phi_j \right\rangle & -\left\langle \frac{1}{\ell} \tilde{e}^2 q_\theta, \phi_j \right\rangle \end{bmatrix}$$

where $\langle f, g \rangle = \int_0^T f(\tau) g(\tau) d\tau$ is evaluated numerically via FFT convolution.

---

## 3. MSTLS Thresholding & Scale Regularization

To isolate the dominant balance without over-fitting observational noise:

1. **Scale Invariance Normalization:** Columns of $\mathbf{G}$ are column-normalized by their $L_2$ norms: $\mathbf{G}_{\text{norm}} = \mathbf{G} \mathbf{D}^{-1}$, where $\mathbf{D}_{ii} = \Vert{}\mathbf{G}_{:,i}\Vert{}_2$. This prevents large-magnitude features (like $\tilde{e}^3$) from dominating small-magnitude features ($q_\theta^2$).
2. **Sequential Thresholding:** The Modified Sequential Thresholded Least Squares (MSTLS) algorithm solves:

$$\hat{\boldsymbol{\Xi}} = \arg\min_{\boldsymbol{\Xi}} \Vert{}\mathbf{G}_{\text{norm}} \boldsymbol{\Xi} - \mathbf{b}\Vert{}_2^2 + \lambda \Vert{}\boldsymbol{\Xi}\Vert{}_1$$



Iteratively zeroing terms below threshold $\lambda$ removes unphysical cross-terms (such as $S q_\theta$ or $\tilde{e}^4$) automatically.

## 4. Phase 4 Julia Implementation Architecture (`src/wsindy/identification.jl`)

In `GSPTSBL.jl`, Phase 4 wraps `DataDrivenDiffEq.jl` and `DataDrivenSparse` to execute parameter identification directly from processed field data arrays (e.g., CASES-99 towers):

```julia
using DataDrivenDiffEq
using DataDrivenSparse
using LinearAlgebra

"""
    identify_gspt_closures(tau, e_tilde, q_theta, S, T_s, params; lambda=1e-2)

Runs the WSINDy weak-form regression to extract (c_m, c_w, c_theta, C_theta).
"""
function identify_gspt_closures(tau, e_tilde, q_theta, S, T_s, params; lambda=1e-2)
    # 1. Compute effective geometry & stratification along trajectory
    z_eff = params.z_1 - params.d + params.z0m
    ell   = (params.kappa * z_eff) / (1.0 + params.kappa * z_eff / params.ell_inf)
    h_sbl = params.h_min .+ params.L_e .* e_tilde
    theta_z = max.(0.0, (params.T0 .- T_s) ./ h_sbl)

    # 2. Construct DataDriven Problem State Matrix
    X = hcat(e_tilde, q_theta)'
    U = hcat(S, T_s, ell, theta_z)'

    # 3. Define Explicit Polynomial Feature Basis
    @parameters c_m c_w c_theta C_theta
    @variables u[1:2] p[1:4] # u=[e_tilde, q_theta], p=[S, T_s, ell, theta_z]

    # Basis terms matching desingularized GSPT ODEs
    basis_terms = [
        0.5 * p[3] * p[1]^2 * u[1],             # c_m feature
        -p[4] * u[1]^3,                         # c_w feature
        -(params.g / params.theta0) * p[3] * u[2]^2, # c_theta feature
        -(1.0 / p[3]) * u[1]^2 * u[2]           # C_theta feature
    ]
    basis = Basis(basis_terms, u, parameters=p)

    # 4. Solve Weak-Form Sparse Identification
    dd_prob = ContinuousDataset(X, tau; u = U)
    opt = STLSQ(lambda)
    res = solve(dd_prob, basis, opt, digits=4)

    return result(res)
end

```
